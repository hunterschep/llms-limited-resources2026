# Submission Packaging

For each final candidate, package:

- Model directory.
- Tokenizer.
- Config and generation config.
- Model card draft.
- Data statement.
- Contamination statement.
- Training summary.
- Evaluation summary.
- Exact commands.

Requirements:

- One model per track.
- No task-specific adapter switching.
- No live retrieval dependency.
- No hidden ensemble.
- No forbidden data.
- Qwen3.5-family with no more than 2B parameters.

Do not upload publicly without explicit approval.

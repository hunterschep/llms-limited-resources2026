# Local Validation Policy

Local splits are generated by:

```bash
python3 scripts/create_local_splits.py
```

Config:

- `configs/data/local_splits.yaml`

Manifest:

- `data/manifests/local_split_manifest.jsonl`

## Split Rules

- Official train files go to `train`.
- Official monolingual files go to `train` support.
- Large official dev sets use deterministic 70% tune / 30% locked validation.
- Small official dev sets use deterministic 50% tune / 50% locked validation.
- MR dev sets are kept in `locked_validation`.

The split key is deterministic from a fixed seed, file path, and row id. This lets us regenerate exactly the same local evaluation firewall.

## Usage

Tune split:

- Prompt iteration.
- Merge-weight search.
- Training-time evaluation.

Locked validation:

- Final local model comparison.
- Baseline and ablation reporting.
- Guardrail against tuning directly on official dev artifacts.

Final use of any official dev examples in training requires a written policy update and clean reporting in the system description.
